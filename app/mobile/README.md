# Mobile (Expo)

O protótipo web está em `../src`; referências de fluxo mobile estão em `../../tema_connexo` (`login_mobile_*`, `cadastro_mobile_*`).

Para iniciar um app Expo nesta pasta:

```bash
cd mobile
npx create-expo-app@latest . --template blank-typescript
```

Depois alinhe rotas e componentes em `src/` aos fluxos do Connexo (autenticação, painel, documentos).

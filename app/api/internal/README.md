Pacotes sugeridos (evoluir conforme o domínio):

- `domain/` — entidades e regras puras
- `service/` — casos de uso
- `handler/` — HTTP (adaptadores)
- `repository/` — persistência

O protótipo em `../../src/data.jsx` ajuda a nomear entidades iniciais (empresa, clientes, processos, postagens, serviços).
